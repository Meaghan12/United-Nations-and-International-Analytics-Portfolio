# Human Trafficking Risk & Referral Decision-Support System

Immediate public demonstration version.

All cases are synthetic. This version intentionally requires no API key so a reviewer can open it immediately.

## Deploy
Upload `app.py` and `requirements.txt` to the root of the GitHub repository, then deploy the repo in Streamlit Community Cloud with:
- Branch: `main`
- Main file path: `app.py`

The full modular LangGraph/OpenAI implementation, tests, ethics documentation, and governed web-grounding layer can be added later without changing the public portfolio concept.
